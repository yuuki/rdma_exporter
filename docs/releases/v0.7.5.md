# v0.7.5

## Changes

- Build with Go 1.27.4, the security release of 2026-11-10, and update `golang.org/x/sys` to v0.50.0.
- A label value that is not valid UTF-8 (for example a netdev name with `\xff`, which anyone with CAP_NET_ADMIN in a network namespace can choose) no longer makes the whole `/metrics` response fail with HTTP 500: series labelled from sysfs, netlink or ethtool replace such bytes with U+FFFD.
- Skip InfiniBand port directories whose number does not fit in 32 bits instead of truncating it into another port's number in the netlink queries.
- Development baseline: `make check` and the other shared `make` targets, golangci-lint, fuzz targets for the parsers and label building, goroutine-leak checks, CodeQL and govulncheck, Dependabot, and GitHub Actions pinned in `.github/workflows/actions.lock`.
