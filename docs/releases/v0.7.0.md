# v0.7.0

**This release contains breaking changes.** Review the [Breaking changes](#breaking-changes) section and the [Upgrade guide](#upgrade-guide) before upgrading from v0.6.x.

## Breaking changes

### Removed CLI flags and environment variables

The v0.6.x `--enable-*` flags and `RDMA_EXPORTER_ENABLE_*` environment variables have been **removed**. The exporter **refuses to start** if any of the legacy variables is still set (including when empty). The legacy CLI flags are rejected with a rename hint.

| Removed (v0.6.x) | Replacement (v0.7.0) |
| --- | --- |
| `--enable-roce-pfc-metrics` | `--collector.ethtool` / `--no-collector.ethtool` |
| `--enable-netdev-hw-metrics` | `--collector.ethtool` / `--no-collector.ethtool` |
| `--enable-rdma-optional-counters` | `--collector.optional-counters` / `--no-collector.optional-counters` |
| `--enable-rdma-qp-counters` | `--collector.qp-counters` |
| `RDMA_EXPORTER_ENABLE_ROCE_PFC_METRICS` | `RDMA_EXPORTER_COLLECTOR_ETHTOOL` or `--collector.ethtool` / `--no-collector.ethtool` |
| `RDMA_EXPORTER_ENABLE_NETDEV_HW_METRICS` | `RDMA_EXPORTER_COLLECTOR_ETHTOOL` or `--collector.ethtool` / `--no-collector.ethtool` |
| `RDMA_EXPORTER_ENABLE_RDMA_OPTIONAL_COUNTERS` | `RDMA_EXPORTER_COLLECTOR_OPTIONAL_COUNTERS` or `--collector.optional-counters` / `--no-collector.optional-counters` |
| `RDMA_EXPORTER_ENABLE_RDMA_QP_COUNTERS` | `RDMA_EXPORTER_COLLECTOR_QP_COUNTERS` or `--collector.qp-counters` |

Use `--no-collector.X` to disable a collector. `--collector.X=false` is equivalent to `--no-collector.X`. The last explicit CLI flag wins (systemd drop-ins can append negation flags).

### Default collector behavior

On v0.6.x, a zero-flag start collected sysfs counters plus RoCEv2 PFC (on by default) but **not** netdev hardware counters or optional RDMA netlink counters unless explicitly enabled.

On v0.7.0, `--collector.ethtool` and `--collector.optional-counters` default to **true**. A zero-flag start therefore also exports netdev hardware ethtool families and optional RDMA netlink counters (`rdma_netdev_*`, `rdma_pcie_*`, `rdma_phy_*`, `rdma_cc_*`, `rdma_optional_*`, and related series). This increases scrape cardinality and can add netlink work on every scrape.

RoCEv2 PFC and other ethtool hardware families are no longer separate toggles; both are controlled by `--collector.ethtool`. Disabling it turns off PFC as well as buffer, PCIe, PHY, pause, and vport metrics.

To disable optional netlink counters while keeping ethtool metrics (the closest match to a v0.6.x zero-flag start, which already enabled RoCE PFC by default):

```bash
./rdma_exporter --no-collector.optional-counters
```

To collect sysfs counters only (disables RoCE PFC and all ethtool families):

```bash
./rdma_exporter --no-collector.ethtool --no-collector.optional-counters
```

### `rdma_port_info` series identity

`rdma_port_info` now carries a `netdev` label (kernel interface name from sysfs `gid_attrs/ndevs`, empty when absent). Adding a label changes the Prometheus series identity; pre-upgrade `rdma_port_info` time series go stale (typically within about five minutes). Update dashboards and recording rules that match on `rdma_port_info` without `netdev`, and use an explicit join when attaching `netdev` to `{device,port}` counters:

```promql
rdma_port_rcv_data_total
  * on(instance, device, port) group_left(netdev)
  rdma_port_info
```

## Changes

- Replace `--enable-*` flags with `--collector.*` toggles and `--no-collector.*` negation.
- Enable ethtool (RoCEv2 PFC plus netdev hardware families) and optional RDMA netlink counters by default; QP dump stays off unless `--collector.qp-counters` is set.
- Fail closed on leftover `RDMA_EXPORTER_ENABLE_*` environment variables.
- Add a `netdev` label to `rdma_port_info` for joins with port counters.
- Update README, deployment docs, design notes, and bundled Grafana dashboard copy for the new flag model.

## Upgrade guide

1. Remove all `RDMA_EXPORTER_ENABLE_*` variables from systemd units, container env files, and Helm charts before starting v0.7.0.
2. Map old flags to the table above. Example systemd drop-in that kept optional counters off on v0.6.x:

   ```ini
   [Service]
   Environment=
   Environment=RDMA_EXPORTER_COLLECTOR_OPTIONAL_COUNTERS=false
   ```

   Or append `--no-collector.optional-counters` to `ExecStart`.

3. If you relied on RoCE PFC without netdev hardware metrics, note that both now share `--collector.ethtool`; disabling it turns off PFC as well.
4. Refresh Grafana dashboards and PromQL that reference `rdma_port_info` after the `netdev` label rollout.
