# v0.5.0

## Changes

- Continue collecting available RDMA metrics on devices such as EFA that do not expose an `hw_counters/` directory.
- Add EFA sysfs fixtures and regression tests.
- Add `mlxlink_exporter` to collect physical link and optical module metrics from NVIDIA MFT `mlxlink` JSON output.
- Add systemd unit, build configuration, and test fixtures for `mlxlink_exporter`.
