# v0.5.0

## 変更内容

- `hw_counters/` ディレクトリを提供しない EFA などのデバイスでも、利用可能な RDMA メトリクスの収集を継続できるようにしました。
- EFA の sysfs 構成を再現するテストフィクスチャと回帰テストを追加しました。
- `mlxlink_exporter` を追加し、NVIDIA MFT の `mlxlink` JSON 出力から物理リンクと光モジュールのメトリクスを収集できるようにしました。
- `mlxlink_exporter` の systemd ユニット、ビルド設定、テスト用フィクスチャを追加しました。

- `GOCACHE=$(pwd)/.gocache GOMODCACHE=$(pwd)/.gomodcache go vet ./...`
