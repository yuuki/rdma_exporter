# v0.7.1

## Changes

- Log unsupported netdev ethtool stats once at startup instead of on every scrape. Bonded mlx5 setups (for example `bond0`) no longer flood logs with "operation not supported" on each Prometheus scrape. Transient ethtool failures still warn on every scrape.
