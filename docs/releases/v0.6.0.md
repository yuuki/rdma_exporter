# v0.6.0

## Changes

- Add opt-in netdev hardware metrics collection.
- Add opt-in RDMA congestion control (CC) counters.
- Add opt-in live auto-type QP counters.
- Add IEEE 802.3x global pause and pause storm metrics.
- Add QP optional traffic metrics from auto-type dumps.
- Fix sysfs lifespan export as a milliseconds gauge.
- Add mlx5 vport RDMA bytes and packets metrics.
- Add port-level optional RDMA traffic totals.
- Skip vPort RDMA metrics when `sriov_totalvfs` is absent.
- Extend the Grafana dashboard with IEEE 802.3x pause, QP traffic, CC, and port traffic panels.
- Extract `mlxlink_exporter` into a standalone repository (removed from this repo).
- Bump Go, Prometheus libraries, and CI actions.
