# v0.6.0

## 変更内容

- opt-in の netdev ハードウェアメトリクス収集を追加しました。
- opt-in の RDMA CC（congestion control）カウンタを追加しました。
- opt-in の live auto-type QP カウンタを追加しました。
- IEEE 802.3x の global pause と pause storm メトリクスを追加しました。
- auto-type ダンプから QP optional traffic メトリクスを追加しました。
- sysfs lifespan をミリ秒ゲージとして正しく出力するよう修正しました。
- mlx5 vport の RDMA bytes/packets メトリクスを追加しました。
- ポートレベルの optional RDMA traffic totals を追加しました。
- `sriov_totalvfs` がない vPort では RDMA メトリクスを省略するよう改善しました。
- Grafana ダッシュボードに IEEE 802.3x pause、QP traffic、CC、port traffic パネルを追加しました。
- `mlxlink_exporter` を独立リポジトリへ切り出しました（本リポジトリからは削除）。
- Go、Prometheus ライブラリ、CI アクションを更新しました。
